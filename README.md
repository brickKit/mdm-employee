# mdm-employee

组件 `mdm/employee`：员工、任职、账号与员工的关联。使用说明见 `BRICKKIT.md`，修改说明见 `AGENTS.md`。

设计依据：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的边界卡 `docs/zh/07-components/mdm.md`（`mdm/employee` 一节）。按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

## 在项目里使用

在装配项目里 `brickkit add mdm/employee@<版本>`，再按 `BRICKKIT.md` 的“部署前准备”配置。
